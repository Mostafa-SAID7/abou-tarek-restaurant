# 🍲 Koshary Abou Tarek — Modern Restaurant SPA

A clean, modern Single Page Application showcasing Koshary Abou Tarek's legendary Egyptian restaurant. Built with **Vue 3**, **Tailwind CSS**, and **localStorage**.

## ✨ Quick Features

- ✅ Public SPA (no backend needed)
- ✅ Fully responsive & accessible
- ✅ Dark mode & bilingual (AR/EN)
- ✅ Lightning-fast (~95KB gzipped)

## 🚀 Quick Start

```bash
git clone https://github.com/Mostafa-SAID7/restaurant-vue3.git
cd restaurant-vue3
npm install
npm run serve
```

**Dev URL**: http://localhost:5000
